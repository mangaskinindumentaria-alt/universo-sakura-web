# Universo Sakura — sitio web

Sitio web estático responsive para Universo Sakura.

## Archivos
- `index.html`: estructura y contenido del sitio.
- `style.css`: diseño visual, adaptación a celulares y animación de latido del botón de WhatsApp.
- `script.js`: menú móvil y año automático del pie de página.
- `images/logo-universo-sakura.jpeg`: logo proporcionado por la marca.

## Cómo abrirlo en Visual Studio Code
1. Descomprimí la carpeta `universo-sakura-web`.
2. En Visual Studio Code elegí **Archivo > Abrir carpeta** y seleccioná esa carpeta.
3. Abrí `index.html` para revisar el contenido.
4. Para verlo en el navegador, podés abrir `index.html` directamente o usar la extensión Live Server.
